# 시작하기 페이지와 최신 운영 패키지 (2026-11-15)

## 포함 기능

- `/help`: 서비스·도메인 소개, 매니저 역할과 참여 절차, 사용 설명서, 기술 스택·사내망 운영 안내, FAQ.
- PC·모바일 공통 `소통공간 → 시작하기` 메뉴로 접근합니다.
- 참여 의사는 기존 소통 공간에 남기며 매니저 권한은 관리자가 부여합니다.
- 외부 글꼴·이미지·API를 추가하지 않아 사내망에서도 안내 화면을 이용할 수 있습니다.

- PC·모바일 메뉴 이동, 목차 이동, 업무 체크리스트와 FAQ 펼치기 확인.
- 운영 프런트엔드 빌드 ID: `NgJmSE5htGRgjxazMD2ik`.
- 최신 데이터 패키지는 `07-create-transfer.cmd`로 생성합니다. 서버 정상 종료 후 SQL 백업, DB·업로드 사진의 동일 시점 복사와 해시 비교, ZIP 전체 파일 무결성 검사, 원본 재시작을 수행합니다.
- 해당 출력 폴더의 `RESULT.json`이 `COMPLETE`, `allArchiveHashesVerified`와 `originalServerRestarted`가 모두 `true`인지 확인합니다. 데이터 시점과 사진 수는 패키지의 `TRANSFER-SNAPSHOT.json`에 기록됩니다.

## 반입 후 확인

1. ZIP과 `.sha256` 파일을 함께 반입하고 SHA-256을 비교합니다.
2. 최종 경로에 압축을 풀고 관리자 권한으로 `00-relocate.cmd`를 실행합니다.
3. `01-settings.cmd`에서 내부 접속 주소를 확인하고 `02-check.cmd → 03-start.cmd → 04-status.cmd` 순서로 실행합니다.
4. 내부 접속 주소의 `/help`와 `소통공간 → 시작하기`를 확인합니다. 검색·로그인·사진 조회도 확인합니다.
5. 일일 백업은 `08-daily-backup.cmd`를 직접 실행합니다. 자동 실행·예약 작업은 설치하지 않습니다.

운영 DB·업로드·비밀 설정이 포함된 ZIP은 GitHub에 올리지 않습니다. GitHub에는 페이지 소스와 운영 안내 문서만 반영합니다.
