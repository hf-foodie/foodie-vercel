# 체험판 비회원 기능 안내 — 2026-11-18

- 맛집·후기·게시글 등록, 내 글 찾기, 좋아요·답글·맛집 저장 버튼을 사전에 비활성화합니다.
- 잠금 아이콘 및 ‘정식 서비스에서 이용 가능’ 안내를 사용합니다. 체험판은 로그인으로 기능을 해제할 수 없습니다.
- 직접 등록·수정 주소 접근은 기존 PreviewUnavailable 안내를 유지합니다.
- preview-api의 GET/HEAD 외 405 차단과 정적 데이터 조회 구조, Web Analytics 설정은 변경하지 않았습니다.
- PC 1440px·모바일 390px에서 메뉴·후기 상세·검색·맛집게임을 확인했습니다. 비활성 버튼 클릭 시 쓰기 요청 및 좋아요 숫자 변경이 없고, 직접 쓰기 API도 405를 반환합니다.
- 기존 회귀 테스트 45개, lint:check 및 배포 빌드 통과.
- 운영 DB·회원 비밀번호·토큰·비밀 설정은 사용하거나 추가하지 않았습니다.
