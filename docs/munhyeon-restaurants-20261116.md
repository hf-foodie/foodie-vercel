# 문현 식당 및 체험판 메뉴 반영

- 윤우재 문현샤브 칼국수: ID 446, 부산 남구 수영로 26 대림문현시티프라자 158호-161호, 0507-1492-0230.
- 부산에뜬고등어 문현점: ID 447, 부산 남구 수영로 72 1, 2, 3층, 051-633-0789.
- 대표 사진은 사용자가 해당 지점 사진으로 제공한 네이버 이미지 원본을 로컬 정적 파일로 보관한다. 외부 이미지 서버는 실행에 필요하지 않다.
- 대표 메뉴 참고: [윤우재](https://www.diningcode.com/profile.php?rid=FctDk9eRiBF6), [부산에뜬고등어](https://www.diningcode.com/profile.php?rid=HmBUBXL903xY). 가격·영업시간은 추가하지 않았다.
- 데스크톱 메뉴 오른쪽에 맛집 등록·후기 등록을 배치한다. 모바일 메뉴에서도 각각 접근 가능하다.
- 맛집 후기는 `/records`에서 조회한다. 이전 `/blogs` 링크는 검색 조건을 유지하여 이동한다.
- 등록·수정 경로는 정식 서비스 이용 안내만 표시한다. 모든 변경 API는 기존처럼 405로 차단한다.
- 체험판 안내에서 사내망 검증 기록 관련 마지막 문장만 제거한다.
- 공개 정적 데이터에는 계정 비밀번호·토큰을 포함하지 않는다. 실제 운영 DB 파일을 체험판에 배포하지 않는다.
- 이번 변경은 localhost와 체험판 대상이다. 사내망 반입 ZIP과 Foodie 배포 저장소는 갱신하지 않는다.

검증: 기존 프런트 테스트 50개, 체험판 기존 테스트 43개와 추가 테스트 2개 통과. 두 환경의 배포 빌드와 실제 PC·모바일 표시를 확인한다.
