# 맛집빙고와 식당 추가 (2026-11-15)

## 사용 방법과 규칙

맛집게임 > 맛집빙고(/game/bingo)에서 로그인 없이 3×3 미션을 진행한다. 미션을 누르면 등록 식당과 식당 ID 기준 후기 찾기를 보여준다. 식사 후 직접 완료 체크하며 언제든 취소할 수 있다. 가로·세로·대각선은 각각 한 줄이고 전체 완료는 8줄이다. 전체 완료 기념 배지는 이 브라우저 안의 표시이며 서버 포인트나 실제 방문 인증이 아니다.

9개 미션: 처음 방문, 국밥, 면 요리, 동료 추천, 한식, 혼밥, 다른 지역, 재방문, 새 메뉴. 메뉴·한식·혼밥은 등록 정보로 후보를 찾는다. 개인 경험에 관한 미션은 전체 식당에서 직접 선택한다. 다른 지역은 확인 가능한 국내 시·도만 비교하며 주소가 불명확한 식당은 제외한다. 후보는 6곳씩 페이지 이동한다. 후기가 아직 없는 식당의 연결은 빈 후기 목록으로 이동한다.

완료·취소·배치·기준 지역은 localStorage의 todaymeal.bingo.v1에 저장한다. 최초 판도 저장하며 새로고침 후 복원한다. 다른 기기/브라우저/사내망/Vercel 사이에는 공유되지 않는다. 손상된 기록은 새 판으로 복구하고 저장 불가 시 안내한다. 초기화는 확인 후 체크와 배치를 새로 만든다. 이름·회원 ID 등 개인정보를 기록에 넣지 않는다. 외부 API는 게임의 실행 조건이 아니다.

## 배포 검증

Front 46개, Vercel 39개 자동 검사. 양쪽 프로덕션 빌드. PC 1440px·모바일 390px에서 미션 선택, 완료·취소, 줄 계산, 새로고침 복원, 초기화, 식당 ID 후기 연결을 확인한다. 실제 시·도가 아닌 주소 토큰이 선택지에 포함되던 문제를 제외 처리했다.

보호된 사내망 이전 ZIP은 최신 DB·사진·운영 설정을 담으므로 GitHub에 올리지 않는다. 반입은 ZIP과 SHA-256 파일을 함께 옮기고 전체 압축 해제 → 00-relocate.cmd → 01-settings.cmd → 02-check.cmd → 03-start.cmd → 04-status.cmd 순서다. 기존 계정을 보존하려면 신규 DB 생성 도구를 실행하지 않는다. 공개 Foodie 배포본에는 민감 정보가 제거된 콘텐츠만 포함한다.
