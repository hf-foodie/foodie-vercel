# 주간 랭킹 탐색 상태 복원

- 주차와 본사/지사를 `/ranking?period=previous&office=...`에 보존합니다. 새로고침·후기 목록·후기 상세 왕복에도 조건을 유지합니다.
- 기존 `restaurantReturn` 허용 경로에 `/ranking`을 추가합니다. 외부 URL과 임의 리다이렉트 매개변수는 허용하지 않습니다.
- 후기 찾기를 누를 때 식당 ID와 화면 상대 위치를 같은 탭에 저장합니다. 데이터를 불러온 뒤 해당 카드 위치를 복원하며, 순위에서 사라진 경우 기존 스크롤 위치로 대체합니다.
- 저장소 접근이 차단되어도 탐색은 계속할 수 있습니다. Ctrl/Command 클릭·새 탭 이동은 원래 탭의 복원 기록을 덮어쓰지 않습니다.
- 랭킹 집계·권한·DB 스키마·체험판 쓰기 제한은 변경하지 않습니다.
