# 오늘 점심 월드컵

맛집게임 > 맛집월드컵에서 /game/worldcup으로 이동합니다. 기존 룰렛은 맛집게임 > 오늘의메뉴(/game/roulette)로 분리했습니다. 기존 /game 주소는 /game/roulette로 이동합니다. 로그인 없이 사내망과 Vercel 체험판에서 사용할 수 있습니다.

## 이용 방법과 규칙

1. 모든 지역 또는 근무지를 선택합니다.
2. 8강(7번 선택) 또는 16강(15번 선택)을 시작합니다.
3. 더 먹고 싶은 메뉴를 선택하면 승자가 다음 라운드로 진출합니다.
4. 우승 메뉴의 등록 식당과 대표 메뉴·주소를 확인하고 ‘후기 찾기’로 이동합니다.

- 등록 식당의 대표 메뉴와 메뉴별 별칭을 대조합니다. 식당명이나 주소만으로 메뉴를 추정하지 않습니다.
- 연결 가능한 메뉴 중 중복 없이 무작위로 대진을 구성합니다. 메뉴가 부족한 근무지는 시작을 막고 안내합니다.
- 결과 식당은 6곳씩 표시하며 후기 링크는 식당 ID를 사용합니다. 후기가 없는 식당은 빈 후기 목록을 표시합니다.
- 화면의 그림은 메뉴 종류를 나타내는 아이콘이며 실제 식당 음식 사진이 아닙니다.
- 대결 상태는 현재 화면에서만 유지됩니다. 새로고침하거나 다른 페이지로 이동하면 초기화됩니다.
- 취향·선택 결과를 서버에 저장하지 않습니다. 추가 외부 API, 이미지 CDN, 로그인, DB 변경이 필요하지 않습니다.
- 사내망은 기존 내부 식당 데이터를, Vercel은 기존 공개 승인된 정적 식당 데이터를 사용합니다. 실제 판매 여부는 방문 전 확인해야 합니다.
