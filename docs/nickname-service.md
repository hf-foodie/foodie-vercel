# 닉네임 기반 소개와 서비스 안내

- 소개 화면의 지정 기여자는 회원 계정 1690의 현재 닉네임을 조회하여 표시합니다. 실명과 회원 번호를 화면에 표시하지 않습니다.
- 공개 조회 `/contributors/featured`는 지정 기여자의 닉네임만 반환합니다. 임의 회원 조회 파라미터와 계정·이메일·권한·복구 정보는 제공하지 않습니다.
- 비활성·없는 계정 또는 조회 장애 시 ‘맛집 제보 기여자’로 표시하며 실명으로 되돌리지 않습니다.
- 공지와 시작하기에 ‘닉네임 기반의 블라인드 서비스’와 ‘※ 회원가입 시 사용한 닉네임 기반으로 운영’을 추가했습니다. 계정·운영 기록의 수집이 전혀 없다는 의미로 안내하지 않습니다.
- 기존 24시간 공지 숨김 설정은 유지합니다. 숨김 기간에는 시작하기에서 안내를 확인할 수 있습니다.
- DB 스키마나 회원 데이터를 변경하지 않습니다. 운영 패키지의 최신 DB·사진 백업과 전체 파일 해시를 확인합니다.

SBOM 생성 시 새 서버 빌드를 검토하려면 `node scripts/generate-security-inventory.cjs <검사한 JAR 경로>`를 사용할 수 있습니다. OSV 보고서의 JAR 해시와 일치해야 합니다.
