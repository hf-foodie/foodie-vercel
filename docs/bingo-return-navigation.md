# 맛집빙고 후기 탐색 후 복귀

- 선택한 미션, 식당 목록 페이지, 기준 지역을 빙고 URL에 보존한다.
- 미션·지역 변경은 첫 페이지로 이동하며 완료 체크와 브라우저 저장은 기존 정책을 유지한다.
- 후기 찾기 링크에 빙고 복귀 주소를 전달한다. 후기 목록의 복귀 링크, 후기 상세의 복귀 버튼·경로 안내, 브라우저 뒤로가기 모두 지원한다.
- 이동할 때 식당 카드의 화면 내 위치를 탭의 세션 저장소에 기록하고, 복귀 후 글꼴·목록 렌더링을 기다려 같은 위치를 복원한다. 기존 목록 복원 도구를 재사용한다.
- 위치 정보는 24시간 유효하며 복원 후 제거한다. 사용자가 스크롤·터치·키 입력을 시작하면 자동 복원을 중단한다. 저장소 사용이 제한되어도 미션·페이지 URL과 후기 이동은 동작한다.
- 허용된 내부 경로만 복귀 대상으로 사용한다. 잘못된 미션·페이지는 기본값으로 처리하고, 목록이 줄어들면 마지막 유효 페이지로 제한한다.

## 검증

- Front 48개, Vercel 41개 테스트 및 프로덕션 빌드 통과.
- 미션·목록 페이지·기준 지역이 후기 목록 및 상세 URL을 거쳐 보존되는 회귀 테스트 추가.
- PC 1440×1000: 혼밥하기 2페이지 → 대왕김밥 후기 상세 → 빙고 복귀. 후기 버튼 화면 위치 477.586px로 동일.
- 모바일 390×844: 면 요리 2페이지 → 형제반점 후기 → 브라우저 뒤로가기. 후기 버튼 화면 위치 399.688px로 동일.
- localhost 모바일: 혼밥하기 2페이지에서 키보드로 후기 이동 후 복귀 링크 사용, 399.492px로 동일.
- localhost PC: 청실홍실 후기 → 뒤로가기, 578.977px로 동일. 선택 미션과 2페이지 유지.
- 기준 지역 서울·다른 지역 맛집·2페이지 새로고침 유지. 잘못된 미션과 음수 페이지는 처음 가본 식당·1페이지로 처리.
- 사진과 기존 완료 체크 상태 유지. DB 스키마와 식당 데이터 변경 없음.
