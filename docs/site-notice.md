# 첫 방문 개편 공지

- 사이트 공통 레이아웃에서 KRDS 확인 패턴을 참고한 접근성 대화상자를 제공합니다.
- 디자인 개편, 회원의 맛집 등록·수정 제안, 매니저·관리자 검토 정책을 안내합니다.
- 소개(/about), 시작하기(/help), 기술과 운영(/technology)는 상대 경로로 연결하여 사내 도메인 이전 후에도 동작합니다.
- 일반 닫기: 현재 탭 세션에서 다시 표시하지 않습니다. 하루 숨김 토글: 해당 브라우저의 로컬 저장소에 선택 시점부터 24시간 만료값을 저장합니다.
- 저장소가 차단되어도 닫기와 바로가기를 이용할 수 있습니다. 하루 숨김 저장 실패는 공지 안에서 안내합니다.
- 공지 내용과 저장 키는 SiteNotice.tsx 및 site-notice.ts에서 관리합니다. 새 공지를 강제로 표시해야 하는 경우에만 버전 키를 변경합니다.
- 참고: https://www.krds.go.kr/html/site/global/global_11.html
