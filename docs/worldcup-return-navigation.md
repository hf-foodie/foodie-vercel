# 맛집월드컵 우승 결과 복귀

- 우승 메뉴, 근무지 조건, 8강·16강 설정, 식당 목록 페이지를 결과 주소에 보존한다.
- 후기 목록·후기 상세의 맛집월드컵 복귀 링크/버튼과 브라우저 뒤로가기를 지원한다.
- 선택한 식당 카드의 화면 위치를 세션 저장소에 기록하고 복귀 후 기존 목록 복원 도구로 같은 위치를 복원한다. 위치 기록은 24시간 유효하며 사용자의 직접 스크롤·터치·키 입력이 우선한다.
- 새로고침해도 우승 결과와 페이지를 유지한다. 다시 도전하기는 우승 결과와 페이지를 초기화하고 근무지·대결 규모는 유지한다. 진행 중 대진표의 별도 영구 저장은 추가하지 않는다.
- 우승 메뉴에 연결된 식당은 현재 등록 정보를 사용한다. 유효하지 않거나 해당 근무지에 더 이상 없는 메뉴는 설정 화면으로 안내한다. 잘못된 규모·페이지는 기본값으로 처리하고 줄어든 목록의 페이지는 마지막 유효 페이지로 제한한다.
- 로그인이나 DB 저장 없이 사내망·Vercel 체험판에서 동일하게 동작한다. DB 구조·식당·후기 데이터는 변경하지 않는다.

## 검증

- Front 테스트 50개, Vercel 테스트 43개와 프로덕션 빌드 통과.
- 우승 메뉴·근무지·규모·식당 페이지가 후기 목록과 상세를 거쳐 유지되는 회귀 테스트, 잘못된 결과 주소 및 현재 근무지 정보 대조 테스트 추가.
- PC 1440×1000에서 8강 7회 선택 → 파스타 우승 → 식당 2페이지 → 후기 → 목록 복귀. 우승·2페이지 유지, 3found 후기 버튼 477.766px로 동일.
- 모바일 390×844에서 본사 16강 15회 선택 → 짜장면 우승 → 화락만리 후기 → 브라우저 뒤로가기. 버튼 399.398px로 동일.
- 모바일 본사 짜장면 2페이지 → 흥미원 후기 상세 → 월드컵 복귀. 버튼 399.672px로 동일, 2페이지 유지.
- localhost PC 브라우저 뒤로가기 및 모바일 후기 상세 복귀에서도 동일 위치 확인.
- 새로고침의 결과·페이지 유지, 재도전 시 우승 초기화와 본사·16강 유지, 잘못된 우승 주소의 안내·8강 기본값 확인.
