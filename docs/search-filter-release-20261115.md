# 화면 및 검색 필터 갱신 (2026-11-15)

## 포함 변경
- 소개: 청년이사 17기 / 관리자 (ICT운영실 문성욱) 제목을 나란히 표시. 기여자는 회원 1690의 현재 닉네임으로 표시.
- 시작하기·기술과 운영: 요청한 문구와 문단 내 줄바꿈 반영.
- 검색·필터 탭과 아이콘, 키보드 전환, 탭 간 입력값 유지.
- 홈과 같은 지역 목록(모두 포함) 선택, 별도 상세 주소 입력, 주소·식당명 자동완성.
- PC에서 주소 폭 확대, 식당명 폭 축소. 모바일에서는 한 열 배치.
- 태그 입력 예: #점심, #혼밥. 입력한 태그 중 하나가 포함된 후기를 검색하며 중복 태그를 제거.
- 지역과 주소 조건은 함께 적용. 결과 수·페이지 수는 전체 검색 결과를 기준으로 계산.
- 후기 상세 왕복 시 지역·주소·식당명·태그 조건 보존.

## 검증
- Front 타입 검사·린트 신규 오류 검사·기존 테스트 34개·운영 빌드 통과.
- Server 기존 전체 테스트와 추가 지역/주소/다중 해시태그 통합 테스트 통과.
- PC·모바일 지역 선택, 주소·식당명 자동완성, 입력 예시, 다중 태그 조건 적용 확인.
- 앱 변경에 따른 DB 스키마 변경 없음.
- SBOM은 배포된 새 Server JAR과 일치하도록 갱신. 준비 환경 OSV 검사 128개 의존성, 운영 라이브러리 80개, 확인된 경고 0건.

## 사내망 반입
1. 최신 이전 패키지는 07-create-transfer.cmd로 생성한다. 서버 정상 종료, SQL 백업, DB·업로드 스냅샷, ZIP 파일별 해시 검증, 원본 재시작을 자동 수행한다.
2. transfer 아래 해당 실행의 RESULT.json에서 COMPLETE, allArchiveHashesVerified=true, originalServerRestarted=true를 확인한다.
3. foodie-intranet.zip과 같은 이름의 .sha256 파일만 함께 반입한다. 운영 DB와 비밀 설정이 포함되므로 GitHub에 올리지 않는다.
4. 관리자 PowerShell에서 ZIP의 SHA256을 비교하고 쓰기 가능한 경로에 압축 해제한다.
5. 00-relocate.cmd → 01-settings.cmd → 02-check.cmd → 03-start.cmd → 04-status.cmd 순서로 실행한다.
6. 내부 주소로 로그인·검색·사진을 확인한다. 08-daily-backup.cmd는 수동 실행하며 최근 30개 정책을 유지한다. 자동실행·예약 작업은 설치하지 않는다.

자세한 설치와 복구 절차는 INSTALL-CHECKLIST.md 및 관리자 운영 가이드를 따른다.
